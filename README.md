## Отчёт

Главный файл — [vkr.tex](vkr.tex). Обзор с выводами и предварительные
результаты первой фазы занимают две страницы. Вместе с титулами,
аннотацией, постановкой задачи и литературой PDF содержит семь страниц.

## Сборка

Нужны XeLaTeX, BibTeX, latexmk и шрифты CMU. Из корня репозитория:

```sh
make vkr.pdf
```

PDF создаётся локально и не хранится в Git.
