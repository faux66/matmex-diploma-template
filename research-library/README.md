# Каталог источников PySATL-expert

[Текстовый каталог](catalog.md) · [Интерактивная страница](index.html) · [Данные](catalog.json)

В каталоге 123 карточки: 107 статей, две книги, диссертация,
научный отчёт и 12 документов. Карточки содержат ссылки, краткое описание,
возможное применение и ограничения проверки источника.

Для ВКР выделены [восемь основных материалов](../docs/MATERIALS.md).
[Требования](../docs/REQUIREMENTS.md) связаны с источниками и
[задачами работы](../docs/OBJECTIVE.md).

## Просмотр

На GitHub удобно читать `catalog.md`. Интерактивный `index.html` нужно
скачать и открыть в браузере; он работает без сервера. Поиск, фильтры и
заметки работают локально. Заметки и статусы чтения хранятся в браузере,
для переноса доступны экспорт и импорт. Они не отправляются в репозиторий.

Обозначения F01–F08 и Q01–Q06 в карточках относятся к ранней матрице
требований; текущие требования приведены в документе ВКР по ссылке выше.

## Обновление

Данные редактируются в `catalog.json`, идентификаторы карточек сохраняются.
Команда `python3 rebuild_catalog.py` проверяет структуру и обновляет
`catalog.md` и встроенные данные и сценарий в `index.html`.
