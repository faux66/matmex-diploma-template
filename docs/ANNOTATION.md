# Название и аннотация ВКР

## Название

**PySATL-expert: Рекомендательная система распознавания распределений**

## Название на английском языке

**PySATL-expert: A Recommender System for Probability Distribution Identification**

## Аннотация

Выбор вероятностного распределения по наблюдаемой выборке является одним из
этапов статистического анализа данных. Он включает рассмотрение нескольких
распределений, оценивание их параметров и интерпретацию результатов критериев
согласия. При большом числе кандидатов и доступных проверок этот процесс
требует времени и участия специалиста. Рекомендательная система может помочь
сузить круг рассматриваемых распределений и предоставить информацию для
дальнейшего выбора.

Работа посвящена развитию PySATL-expert — рекомендательной системы
распознавания распределений по одномерным числовым выборкам. Существующий
прототип использует характеристики выборки и статистики критериев согласия
для построения рейтинга распределений с помощью модели машинного обучения.
Цель работы — расширить возможности системы, обеспечив настраиваемый
статистический анализ и обоснованное представление рекомендаций.

Планируется развить архитектуру PySATL-expert для подключения дополнительных
распределений, общих и специализированных критериев согласия, а также
различных моделей формирования рекомендаций. Пользователь сможет
настраивать состав анализа и получать рейтинг кандидатов вместе с оценками
параметров, результатами выполненных проверок и сведениями об ограничениях
их применения. Полные результаты статистического анализа будут отделены
от признаков, используемых конкретной моделью.

Исследовательская часть работы предусматривает сравнение способов
представления результатов проверок, включая исходные статистики, p-value
и критические значения, с учётом оценивания неизвестных параметров
распределений. Будут рассмотрены различные методы обучения и формирования
рекомендаций. Экспериментальная оценка позволит сопоставить предложенные
варианты с исходной системой по качеству рейтинга и времени обработки при
различных размерах выборок и параметрах распределений.

Ожидаемыми результатами являются расширенная версия PySATL-expert,
воспроизводимая методика экспериментального сравнения и выводы о применимости
исследованных решений для поддержки работы статистика.
