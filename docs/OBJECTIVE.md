# Цель и задачи ВКР

## Цель

Развить рекомендательную систему PySATL-expert для поддержки выбора
вероятностного распределения по одномерной числовой выборке, обеспечив
настраиваемый статистический анализ и обоснованное представление рекомендаций.

## Задачи

Для достижения этой цели необходимо решить следующие задачи:

1. Развить архитектуру PySATL-expert, обеспечив настройку статистического анализа и расширение набора поддерживаемых распределений, критериев и моделей рекомендаций.
2. Разработать способы представления результатов статистических проверок для формирования рекомендаций с учётом оценивания неизвестных параметров.
3. Исследовать методы формирования рекомендаций и экспериментально сравнить их по качеству и вычислительным затратам.

## Пояснения к объёму задач

- Первая задача включает подключение существующих распределений и специализированных критериев из Criterion; самостоятельная реализация новых специализированных тестов не заявляется. Адаптация к обновлённому API Criterion — техническая подзадача реализации.
- Вторая задача охватывает представления на основе статистик, p-value и критических значений, условия их корректного получения при оценённых параметрах и обоснование повторного использования калибровочных данных. Полезность каждого представления для рекомендаций проверяется экспериментально.
- Третья задача включает исследование моделей, способов обучения и сравнительные эксперименты с исходной системой. Улучшение качества или времени обработки заранее не предполагается.

Задачи сформулированы на всю ВКР.

## Промежуточный результат до декабря

Ориентир — работающий расширенный конвейер и первый сравнительный эксперимент по представлениям результатов проверок.

1. Подготовить сквозной запуск на выбранном наборе распределений и критериев: выборка, оценивание параметров, настраиваемые проверки, структурированные результаты, модель рекомендаций и отчёт.
2. Подготовить сопоставимые представления исходных статистик и результатов с доступной корректной калибровкой.
3. Провести первое сравнение представлений при одинаковых модели и разбиении данных, оценив качество рекомендаций и время обработки.

Этот этап не означает завершения исследования всех моделей или подключения всего каталога Criterion.
